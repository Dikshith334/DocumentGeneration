# Customer Management Sample

1. Start the web application.
2. Enter `Customer Management` as the screen name.
3. Upload `customer-management.component.html`.
4. Paste the contents of `business-rules.txt` into **Business rules**.
5. Optionally add a `.docx` manual or screenshot and select a vision model.
6. Analyze the screen, review the extracted controls and documentation changes, then select an installed text model and generate the manual.

The sample intentionally includes Angular Material controls, Bootstrap layout classes,
bindings, tooltips, a conditional Delete action, sortable table columns, filters, and pagination.
